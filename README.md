# 飲み会クイズ（プロジェクター投影＋スマホ回答）

## ファイル構成（8ファイル・すべて同じフォルダに置く）

| ファイル | 役割 | 誰が開く |
|---|---|---|
| `index.html` | 参加者の回答画面 | 参加者のスマホ（QRから） |
| `host.html` | 進行・投影画面 | 司会のPC → プロジェクター |
| `admin.html` | 問題作成画面 | 司会（事前準備） |
| `config.js` | 設定（Firebase・部屋名・PIN・タイトル） | **ここだけ書き換え** |
| `common.js` | 共通処理（保存・採点・画像） | 触らない |
| `style.css` | 見た目 | 触らない |
| `database.rules.json` | Firebase のルール（貼り付け用） | 手順1で使う |
| `README.md` | この説明 | － |

## 問題の形式と採点

| 形式 | 例 | スマホの操作 | 採点 |
|---|---|---|---|
| 選択 | 1位を当てる／どっちがAさんの絵？（画像） | 番号をタップ | 正解で1点 |
| 並び替え | 年齢が高い順 | ドラッグで上下に並べる | 合っている数÷項目数 |
| 写真マッチング | 子どもの頃の写真は誰？ | 点から点へ線を引く | 同上 |
| グループ分け | パクチー食べられる／食べられない | カードを箱へドラッグ | 同上 |

どの形式も「タップ2回」でも操作できます。

## まずはPCだけでお試し（デモモード・5分）

`config.js` を書き換えていない状態では「デモモード」で動きます（同じPC・同じブラウザのタブ同士だけ）。

1. 8ファイルを1つのフォルダに保存
2. Chrome で `admin.html` を開く（PIN：1234）→ 問題を1〜2問作る
3. 別タブで `host.html` を開く（PIN：1234）
4. さらに別タブで `index.html` を2〜3個開き、それぞれ名前を入れて参加
5. `host.html` のタブで Space キーを押して進行

## 本番の準備（約20分）

### 手順1　Firebase（回答を同期する仕組み）を用意する

1. https://console.firebase.google.com/ を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ プロジェクト名（例：`nomikai-quiz`）を入力 → 続行
   - Google アナリティクスは「オフ」でOK → 「プロジェクトを作成」
3. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーション：**シンガポール（asia-southeast1）** を選択 → 次へ
   - 「**テストモードで開始する**」を選択 → 有効にする
4. Realtime Database の画面上部「ルール」タブを開く
   - 中身を全部消して `database.rules.json` の中身を貼り付け →「公開」
5. 左上の歯車 →「プロジェクトの設定」→ 下の方「マイアプリ」→ `</>`（ウェブ）アイコン
   - アプリのニックネーム（例：`quiz`）を入れて「アプリを登録」（Hosting のチェックは不要）
   - 表示される `const firebaseConfig = { ... }` の中の値を控える
6. `config.js` をメモ帳などで開き、控えた値を貼り付けて保存

```js
firebase: {
  apiKey: "AIza....",                                    // ← 貼り付け
  authDomain: "nomikai-quiz.firebaseapp.com",            // ← 貼り付け
  databaseURL: "https://nomikai-quiz-default-rtdb.asia-southeast1.firebasedatabase.app", // ← 貼り付け
  projectId: "nomikai-quiz",                             // ← 貼り付け
  appId: "1:1234:web:abcd"                               // ← 貼り付け
},
ADMIN_PIN: "1234",   // ← 自分だけが知る番号に変更
```

- `databaseURL` が表示されない場合は、Realtime Database の「データ」タブ上部にある URL（`https://〜.firebasedatabase.app`）をコピーします。

### 手順2　GitHub に置いて公開する

1. https://github.com/ にログイン（アカウントがなければ作成）
2. 右上「＋」→「New repository」
   - Repository name：例 `nomikai-quiz`
   - **Public** を選択 →「Create repository」
3. 作成後の画面で「uploading an existing file」をクリック
   - 8ファイルをまとめてドラッグ＆ドロップ →「Commit changes」
4. リポジトリ上部「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」、Branch：`main` ／ `/(root)` →「Save」
5. 1〜3分待つと、Pages の画面上部に公開URLが表示されます
   - 例：`https://ユーザー名.github.io/nomikai-quiz/`

| 画面 | URL |
|---|---|
| 問題作成 | `https://ユーザー名.github.io/nomikai-quiz/admin.html` |
| 進行・投影 | `https://ユーザー名.github.io/nomikai-quiz/host.html` |
| 参加者 | 進行画面にQRとURLが自動表示されます |

※ ファイルを修正したときは、同じ「Add file」→「Upload files」で上書きすると数分で反映されます。

### 手順3　問題を作る（admin.html）

1. 形式を選ぶ → 問題文・制限時間（秒、0で無制限）を入力
2. 形式ごとの入力
   - 選択：選択肢（文字か画像）を入れて「正解」にチェック
   - 並び替え：**正解の順番（①が先頭）** で入力。保存時にA・B・C…が自動シャッフル
   - 写真マッチング：人物と**正解の写真**をペアで入力。写真番号は自動シャッフル
   - グループ分け：グループ名を入れ、人物ごとに正解のグループを選ぶ
3. 「保存」。一覧の ↑↓ で出題順を変更

### 手順4　リハーサル

自分のPCで `host.html`、スマホ2台で QR から参加し、1問通して動かしてみてください。

## 当日の操作（host.html）

| キー・ボタン | 動き |
|---|---|
| Space / → | 次へ（出題 → 締切 → 正解発表 → 途中経過 → 次の問題） |
| H | 画面下の操作バーを隠す／出す |
| 参加者を選ぶ ＋「この人の結果」 | 選んだ1人の各問の回答・○△×・得点・順位をスクリーンに表示 |
| この問題を出す | 好きな問題に飛ぶ |
| 参加QR | 参加受付画面に戻る（遅れて来た人用） |
| リセット | 参加者・回答・得点を消去（問題は残る） |

- 制限時間を設定した問題は、時間切れで自動的に締切になります。
- 参加者は締切までなら何度でも回答を変更できます。
- ブラウザを F11（Mac は Ctrl+⌘+F）で全画面にすると見やすくなります。

## 注意点

- **データは誰でも読み書きできる簡易設定**です。URLを社外に広めないでください。終了後は Firebase のルールを
  `".read": false, ".write": false` に変えて公開するか、「データ」タブで `rooms` を削除してください。
- 部屋を分けたい（別の飲み会で使う）ときは `config.js` の `ROOM_ID` を変更します。
- 画像は自動で縮小して保存します。無料プラン（保存1GB・転送10GB/月）で50人規模なら足ります。
- 参加者のスマホがインターネットにつながっている必要があります（会場Wi-Fiまたはモバイル回線）。
